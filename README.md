# CNI FIND 🇨🇲

## Perdue. Retrouvée. Restituée.

Plateforme citoyenne permettant de déclarer et retrouver des Cartes Nationales d'Identité au Cameroun.

## Fonctionnalités

- Déclaration de CNI perdue
- Déclaration de CNI retrouvée
- Recherche multicritère
- Matching intelligent
- Vérification d'identité
- Contact sécurisé
- Dashboard administrateur
- Gestion des signalements

## Technologies

- Next.js 15
- TypeScript
- Tailwind CSS
- Prisma
- PostgreSQL Neon
- Cloudinary
- Shadcn UI
- Vercel
