# CNI FIND 🇨🇲

Plateforme citoyenne de recherche et restitution des CNI au Cameroun.

**Tagline:** Perdue. Retrouvée. Restituée.

## 🚀 Installation Progressive Web App (PWA)

CNI FIND est maintenant installable comme une application native sur tous les appareils !

### 📱 Sur Smartphone/Tablette

1. **Ouvrez l'application** dans votre navigateur
2. **Appuyez sur le menu** (⋮ ou ⋯) en haut à droite
3. **Sélectionnez** "Ajouter à l'écran d'accueil" ou "Installer"
4. **Confirmez** - L'application apparaît sur votre écran d'accueil

**Navigateurs supportés:**
- Chrome/Chromium (Android)
- Firefox (Android)
- Safari (iOS 15+)
- Edge (Windows/Android)

### 💻 Sur PC/Desktop

1. **Ouvrez l'application** dans votre navigateur
2. **Cliquez sur l'icône d'installation** (généralement dans la barre d'adresse)
3. **Confirmez** l'installation
4. L'application s'installera comme un programme standard

**Navigateurs supportés:**
- Chrome/Chromium
- Edge
- Firefox

## 📋 Caractéristiques

- ✅ Installable sur tous les appareils
- ✅ Fonctionne hors ligne (mise en cache)
- ✅ Interface responsive (mobile, tablet, desktop)
- ✅ Partage rapide depuis le menu
- ✅ Notifications push (futures)
- ✅ Localisation (FR)

## 🛠️ Technologie

- **Framework:** Next.js 15
- **Langage:** TypeScript
- **Styles:** Tailwind CSS
- **Base de données:** Prisma + PostgreSQL
- **Hébergement:** Vercel
- **Images:** Cloudinary

## 📦 Installation pour le Développement

```bash
# Clone le repository
git clone https://github.com/freddy-20/CNI-FIND.git

# Installe les dépendances
npm install

# Configure les variables d'environnement
cp .env.example .env.local

# Lance le serveur de développement
npm run dev

# Ouvre http://localhost:3000
```

## 🔧 Build et Déploiement

```bash
# Build production
npm run build

# Lance le serveur production
npm start
```
